# 渊下宫外围岛屿素材修复

原渊下宫底图缺少八衢彦之地、八衢姬之地、歧之地三个外围岛屿。用户的 `原神 2026_11_15 17_17_02.png` 位于八衢姬之地，地形无法在旧底图上匹配。

完整官方底图来源：

https://uploadstatic.mihoyo.com/ys-obc/2022/01/05/75379475/d258137dc0e84fc8acbf77b7dc7115da_1941568151557226408.jpeg

处理方式：从 4096×4096 完整图裁取左上 3072×3072，生成三通道彩色 PNG、同尺寸灰度 WebP 和 614×614 彩色预览 WebP。PNG 和 WebP 均使用无损编码。PNG 保留源图色彩，匹配时由读取代码转换为灰度，不将匹配用灰度图覆盖彩色源素材。未修改其他场景素材。

原主岛与完整图独立 SIFT 配准得到 2455 个一致内点，比例约 1.000012、平移约 (-0.034, -0.013)，可以沿用原地图尺寸、(2048, 2048) 原点及比例。新失败截图的独立配准得到 69 个内点，视口中心约为游戏坐标 (-707, 1200)、宽度约 1201。

BetterGI 的回归样本位于独立的 BetterGI.UnitTest.Assets 仓库，包含缩略图和原始 4K 两种分辨率。运行时必须在 PNG 更新后重新生成 SIFT 特征，避免遗留旧地图范围。

本分支仅保存素材及来源说明，不发布 NuGet。BetterGI 本地验证包 `1.0.26-enkanomiya.1` 以正式 1.0.26 为基础，仅替换上述三个文件，避免带入 1.0.27 的其他地图变更；资源维护者合入后需自行选择正式版本并发布，再更新 BetterGI 的 PackageReference。
